Import

Point PiHarness at a GitHub repository. It clones the code onto the Pi, installs the dependencies the repo declares, and keeps the process running across crashes and reboots.

Programs

Loading
Every program must be a long-running process: a server or a loop, not a one-shot script. Full requirements and API in docs/programs.md.

Remote access

A Cloudflare tunnel gives the Pi a public HTTPS address without port forwarding, a static IP, or any inbound hole in your router. Programs you mark public become reachable at that address under /apps/<name>/.

Use my own domain instead of a throwaway address
Anything published this way is on the public internet. Programs are private until you switch them to public, and the harness itself always requires a sign-in.

API tokens

For scripts, and for agents. A token is shown once, can be revoked on its own without signing your browser out, and is scoped: read-only tokens cannot change anything. No token can read a secret's value or mint another token.
