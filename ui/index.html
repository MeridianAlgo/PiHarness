Import

Give it a GitHub repo. PiHarness clones the code onto the Pi and installs whatever the repo asks for. If the program crashes or the Pi reboots, it starts again.

Repos need to be a long-running process that declares its dependencies. Copy the spec and paste it wherever you write code.

Programs

Loading
Programs have to keep running, like a server or a loop. A script that does its job and exits will not work. Full requirements and the API are in docs/programs.md.

Remote access

A Cloudflare tunnel gives the Pi a public HTTPS address. No port forwarding, no static IP, nothing open on your router. Programs you mark public show up at that address under /apps/<name>/.

Use my own domain instead of a throwaway one
Anything you publish here is on the public internet. New programs stay private until you change them, and this page always asks for a sign-in.

Harness updates

PiHarness updates itself from GitHub, the same way it updates your programs. Applying an update restarts the service, so this page will be gone for about a minute and come back on the new version.

API tokens

Tokens let scripts and agents use the API. You see a token once, when you make it. Revoking one does not sign your browser out. Read-only tokens cannot change anything, and no token can read a secret or make another token.
